#### Key Lesson

The FFFF-PZ targets were selected for Lick (lat 37°) and are heavily biased
toward high declination (Dec 48-85°). For a proper Keck run, a fresh target
query with Dec constraints appropriate for Keck's latitude is needed. The 9.7h
night could accommodate 15+ targets, but we can only observe 4 of the Lick targets.

#### Scheduling Bug Fix

Initial scheduling code scheduled FRB20231223B at 22:22 HST when its observable
window didn't start until 00:32 HST (it was below horizon). Fixed by implementing
proper window-aware scheduling that:
1. Sorts targets by window start time
2. Waits for target to rise if necessary
3. Validates observation fits within observable window
